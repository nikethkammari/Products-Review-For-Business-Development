## 📌 Executive Summary
This repository contains the end-to-end data engineering, financial modeling, and strategic portfolio optimization for **Nexora Technologies Pvt. Ltd.** (Case Study ID: **SIM-012**). 

The primary objective of this project is to address top-line sales masking hidden product-level unprofitability across a catalog of 500 SKUs. By evaluating sales orders, returns, marketing performance, and customer reviews, this analysis classifies the portfolio into **5 core strategic archetypes** and provides actionable recommendations to maximize net gross profit.
